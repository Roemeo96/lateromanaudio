Weltgeist Features

Base
Sets the expression position at low input levels.
Sensitivity
Sets how much the expression position moves as the input level changes.
Rise
Sets the response speed as the input level rises.
Fall
Sets the response speed as the input level falls.
Invert
Reverses the direction of expression movement as the input level changes.

Your setup

Compatibility Notice

Linearity and constant total resistance are not guaranteed across the full emulated travel. Use Weltgeist only with devices that do not require a specific potentiometer resistance. The expression output is not a true CV signal. Compatibility varies by device.
